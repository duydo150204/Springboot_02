# Springboot_02

REST API demo cửa hàng  (danh mục, sản phẩm, khách hàng, đơn hàng), xây dựng bằng Spring Boot 4, Java 21 và MariaDB/MySQL.

## Cách chạy
1. bật module MySQL trong XAMPP (user `root`, mật khẩu trống).
2. Chạy `.\gradlew.bat bootRun` (macOS/Linux: `./gradlew bootRun`).
3. Mở http://localhost:8080. Trang này redirect sang Swagger UI

Database `shop`, các bảng và dữ liệu mẫu được tạo tự động
